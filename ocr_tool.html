圖片文字辨識工具

上傳圖片或 ZIP，OCR 辨識後輸出文字檔

主題：

OCR 辨識完全在你的瀏覽器本機執行，圖片 不會上傳到任何伺服器。若另外開啟「翻譯」功能，辨識出的文字才會傳送到第三方翻譯服務（詳見翻譯設定說明）。

1加入圖片或 ZIP 檔案

拖曳圖片 / ZIP 檔到這裡，或點擊選擇檔案
要辨識 PDF？請到 PDF 工具。

2設定辨識選項

辨識語言（可複選，會同時辨識所選語言）：
第一次使用某語言時，瀏覽器需下載語言資料檔（約數 MB），請保持網路連線。勾選越多語言，辨識速度會越慢，建議只勾選圖片實際會出現的語言。
輸出方式：
進階設定（表格截圖 / ID 碼 / 純數字辨識常錯，建議調整這裡）
代碼／ID／數字（英數字+底線） 純數字（含小數點） 日期時間格式 清空
你這次上傳的表格（ID碼＋小數點數字＋時間戳記）建議點「代碼／ID／數字」，並把語言改成「純英文／數字」。

3翻譯設定（選用）

原文語言： → 目標語言：

⚠️ 翻譯會呼叫免費的第三方服務（MyMemory），辨識出的文字內容會傳送到該服務的伺服器進行翻譯，不再只留在本機瀏覽器。若圖片內容涉及公司機密或個資，請不要勾選這個功能。免費額度約每日 5000 字，超過額度翻譯會失敗（OCR 結果本身不受影響）。翻譯結果會附加在原文之後，一起輸出到 .txt 檔。
