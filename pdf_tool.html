PDF 工具

PDF 文字辨識（可輸出 HTML 報告）、合併、拆分、壓縮、解鎖

主題：

所有 PDF 處理皆在你的瀏覽器本機完成，檔案不會上傳到任何伺服器。若另外開啟「翻譯」功能，辨識出的文字才會傳送到第三方翻譯服務。

1加入 PDF 檔案

拖曳 PDF 檔到這裡，或點擊選擇檔案
PDF 會自動逐頁處理：有文字層的頁面直接擷取文字（不需 OCR，較快較準）；掃描型頁面則自動轉成圖片並用 OCR 辨識。

2設定辨識選項

辨識語言（可複選，會同時辨識所選語言）：
第一次使用某語言時，瀏覽器需下載語言資料檔（約數 MB），請保持網路連線。勾選越多語言，辨識速度會越慢，建議只勾選圖片實際會出現的語言。
輸出方式：
進階設定（表格截圖 / ID 碼 / 純數字辨識常錯，建議調整這裡）
代碼／ID／數字（英數字+底線） 純數字（含小數點） 日期時間格式 清空
你這次上傳的表格（ID碼＋小數點數字＋時間戳記）建議點「代碼／ID／數字」，並把語言改成「純英文／數字」。

3翻譯設定（選用）

原文語言： → 目標語言：

⚠️ 翻譯會呼叫免費的第三方服務（MyMemory），辨識出的文字內容會傳送到該服務的伺服器進行翻譯，不再只留在本機瀏覽器。若圖片內容涉及公司機密或個資，請不要勾選這個功能。免費額度約每日 5000 字，超過額度翻譯會失敗（OCR 結果本身不受影響）。翻譯結果會附加在原文之後，一起輸出到 .txt 檔。

    壓縮 PDF 檔案大小

    中度／強力會把每頁轉成圖片，文字將無法選取或搜尋。若壓縮後沒有變小，不會下載。

    解鎖 PDF

    僅限處理你本人有權解鎖的檔案。解鎖後會輸出為影像式 PDF（每頁轉成圖片），文字將無法選取，檔案也可能變大。
